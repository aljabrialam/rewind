# Sandbox Capability Contract (spec 000)

One enforced definition of what the sandbox runtime can do. No feature may call a
lifecycle operation that has not been verified on this account and recorded in
the map. Full spec: [`specs/000-sandbox-capability-contract/`](../specs/000-sandbox-capability-contract/).

## The pieces

| File | Role |
|---|---|
| `.rewind/capability-map.toml` | The verified declaration — operation name, required sandbox class, asserted post-condition, experimental marker. Generated by `tools/spine_test.py`, never hand-edited. |
| `src/rewind/capabilities.py` | Loads + validates the map **at import**. An undeclared or incomplete operation raises `CapabilityError` (an `ImportError`) — the failure is at load time, not demo time. Also holds the declared bounds (`READINESS_WAIT`, `SLOT_WAIT`, `DESTROY_RETRIES`, …). |
| `src/rewind/ports.py` | The single seam. `PORT_OPERATIONS` is checked against the map on import. Types: `Handle`, `ExecResult`, `CallRecord`, `RuntimeCallError`, `UnconfirmedDestroyLeak`. |
| `src/rewind/providers.py` | The only file that imports the vendor SDK. `DaytonaProvider` (live) and `FakeProvider` (offline) implement the same contract: per-call class check, bounded waits/retries, required stop+delete intervals, concurrency ceiling, error classification. `classify()` maps any failure to `retryable` / `capacity` / `terminal`. |
| `src/rewind/recording.py` | `RecordingProvider` captures live calls to JSON fixtures (with provenance); `ReplayProvider` serves them offline. Hand-written fixtures are prohibited. |

## Guarantees

- **Nothing invented** — `import rewind.ports` fails if the code declares an operation the map does not contain (FR-000-03).
- **One port** — an AST test asserts only `providers.py` imports `daytona` (FR-000-02).
- **Class-checked** — an operation against an unsupported sandbox class is refused before any runtime call (FR-000-04).
- **Opaque ids** — runtime identifiers are carried verbatim; nothing parses or builds one (FR-000-06).
- **Bounded + cleaned up** — every sandbox gets stop + delete intervals and must accept a command before it is handed back; it is destroyed on the return and the raise path; an unconfirmed destroy is retried, then recorded as a leak that still counts against the ceiling (FR-000-08, 08a, 09).
- **Ceiling enforced** — live count never exceeds the verified account quota; a surplus fan-out request waits a bounded time then fails `capacity`, leaving siblings live (FR-000-11).
- **Observable** — every runtime call produces a `CallRecord` (operation, outcome, elapsed, waited, retries); every failure carries exactly one class (FR-000-07, FR-000-10).

## Running

```bash
pytest -q                       # offline: base + lifecycle + classification layers
pytest tests/contract -m live   # live drift check, < 30s (needs DAYTONA_API_KEY)
python tools/spine_test.py      # re-verify the account and regenerate capability-map.toml
```
